# CallStats — статистика звонков и операторов

CallStats — это небольшой сайт на вашем сервере FreePBX. Он каждую минуту читает журнал очередей и историю звонков, считает по ним статистику (сколько звонков, сколько отвечено, пропущено, сколько говорил каждый оператор, паузы и т. д.) и показывает её в браузере. Есть журнал звонков по каждому оператору и поиск записей разговоров. Ничего в FreePBX программа не меняет: она только читает данные.

Все команды ниже выполняются на сервере от пользователя `root` в программе PuTTY.

## 1. Установка

Перед установкой убедитесь, что в FreePBX включена запись разговоров, иначе в отчётах не будет записей для прослушивания. Для очередей: **Applications → Queues → (нужная очередь) → «Call Recording»**. Для внутренних номеров операторов: **Applications → Extensions → (номер) → «Recording Options»**. После изменений нажмите **Submit** и красную кнопку **Apply Config**.

1. Откройте WinSCP, подключитесь к серверу и скопируйте файл `callstats-ГГГГММДД.tgz` в папку `/root`.
2. В PuTTY войдите на сервер как `root` и выполните по очереди:

```
cd /root
tar xzf callstats-*.tgz
cd callstats-*
bash install/install.sh
```

3. Установщик сам создаст базу данных и пользователей, настроит Apache и расписание (cron). В середине он спросит:
   - `Логин:` — придумайте логин для входа на сайт;
   - `Пароль (не менее 8 символов):` — придумайте пароль (при вводе буквы не видны, это нормально);
   - `Повторите пароль:` — введите тот же пароль ещё раз.
4. После этого установщик загрузит историю звонков с 1 августа 2026 года. Это может занять несколько минут. В конце он напечатает итоги и адрес сайта.

Если у `root` в MariaDB есть пароль, запустите так (подставьте свой пароль):

```
MYSQL_ROOT_PASS='ваш_пароль' bash install/install.sh
```

Установку можно безопасно запускать повторно.

## 2. Как открыть сайт

В браузере откройте `https://<адрес_сервера>/callstats/` — например `https://192.168.1.10/callstats/`. Адрес в конце обязательно с косой чертой. Установщик в конце печатает готовый адрес.

Введите логин и пароль, которые вы создали при установке. Без входа не открывается ни одна страница и ни одна запись разговора.

## 3. Первый вход: имена операторов

В меню откройте раздел **«Операторы»** и впишите имена операторов напротив их внутренних номеров. После этого во всех отчётах будут видны имена, а не номера.

## 4. Обновление

1. Скопируйте новый архив `callstats-ГГГГММДД.tgz` в `/root` через WinSCP.
2. Выполните:

```
cd /root
tar xzf callstats-НОВЫЙ.tgz
cd callstats-НОВЫЙ
bash install/install.sh
```

(вместо `callstats-НОВЫЙ` подставьте имя нового файла/папки). Ваши настройки, пароли и собранная статистика сохранятся. Если в инструкции к обновлению сказано пересчитать историю, добавьте `--rebuild`:

```
bash install/install.sh --rebuild
```

## 5. Смена пароля или логина

```
runuser -s /bin/bash asterisk -c "cd / && /usr/bin/php /opt/callstats/bin/set-password.php"
```

Программа спросит новый логин и пароль. Старый вход перестанет работать.

## 6. Пересчитать историю заново

Если цифры выглядят странно или вы обновили программу, историю можно пересчитать за нужный период (даты в формате ГГГГ-ММ-ДД):

```
runuser -s /bin/bash asterisk -c "cd / && /usr/bin/php /opt/callstats/bin/rebuild.php --from=2026-08-01 --to=2026-10-21"
```

В конце программа печатает счётчики. Пересчёт безопасен: данные FreePBX не затрагиваются.

## 7. Сверка цифр за вчера

Сверка нужна, чтобы убедиться, что программа не потеряла и не придумала звонки. Нужно сравнить два числа за вчерашний день: сколько звонков зашло в очередь по журналу Asterisk и сколько звонков в очереди записано в базе CallStats.

**Шаг 1.** Число звонков по журналу Asterisk (учитываются и прошлые, сжатые файлы журнала). Вставьте в PuTTY целиком:

```
S=$(date -d "yesterday 00:00" +%s); E=$(date -d "today 00:00" +%s)
zcat -f /var/log/asterisk/queue_log /var/log/asterisk/queue_log-* 2>/dev/null \
  | awk -F'|' -v s=$S -v e=$E '$1>=s && $1<e && $5=="ENTERQUEUE" {n++; id[$2]=1} END {c=0; for (k in id) c++; print "ENTERQUEUE строк: " n+0; print "уникальных звонков: " c}'
```

Важно число после «уникальных звонков».

**Шаг 2.** Число звонков в очереди, записанных в базе CallStats за вчера:

```
mysql callstats -e "SELECT COUNT(*) AS zvonkov_v_ocheredi FROM calls WHERE kind='queue' AND started_at >= CURDATE() - INTERVAL 1 DAY AND started_at < CURDATE()"
```

Если у `root` в MariaDB есть пароль, добавьте `-p` после `mysql` и введите пароль.

**Шаг 3.** Сравните: число «уникальных звонков» из шага 1 и число из шага 2 должны быть равны. Если они отличаются хотя бы на единицу, откройте журнал звонков за вчера и найдите расхождение (см. следующий раздел), а затем покажите оба числа разработчику.

## 8. Если что-то не так

**Цифры странные.** Откройте журнал звонков нужного оператора и найдите звонок. У каждого звонка есть блок **«Источник»** — раскройте его: там видны исходные строки журнала очередей, по которым посчитан звонок. Сделайте снимок экрана и покажите разработчику. Также попробуйте пересчитать историю (раздел 6).

**Данные перестали обновляться.** Проверьте, что расписание запускается и нет ошибок:

```
grep callstats /var/log/cron | tail -5
tail -20 /var/log/callstats.log
```

В первой команде должны быть свежие строки (каждую минуту). Во второй — сообщения об ошибках сборщика (пусто — значит ошибок нет). Журнал `/var/log/callstats.log` автоматически ротируется раз в неделю.

**Сайт не открывается.** Проверьте адрес (с `/callstats/` на конце) и что Apache работает: `systemctl status httpd`. Проверка настроек: `apachectl configtest`.

**Запись разговора показывает «файл не найден».** Для безопасности программа не открывает записи, лежащие в папках-ссылках (symlink) по датам. Такие записи нужно прослушивать другим способом (через FreePBX).

## 9. Удаление

Удалить программу (сайт, расписание и папку `/opt/callstats`), но оставить собранную статистику в базе:

```
bash /opt/callstats/install/uninstall.sh
```

Удалить всё, включая базу `callstats` и пользователей базы данных (статистика пропадёт безвозвратно):

```
bash /opt/callstats/install/uninstall.sh --drop-db
```

Скрипт попросит подтверждение: нужно ввести `yes`. Данные и настройки FreePBX он не трогает.

## 10. Как устроено

Программа лежит в `/opt/callstats` (принадлежит `root`), сайт и сборщик работают от пользователя `asterisk`. Файл настроек `/opt/callstats/config/config.php` содержит пароли к базе: он принадлежит `root`, группа `asterisk`, права `640` — посторонние его прочитать не могут. Это нормально, менять права не нужно.
